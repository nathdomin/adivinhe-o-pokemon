# Adivinhe o Pokémon

Jogo web de adivinhação: descubra o Pokémon sorteado a partir da silhueta e das
dicas sobre suas características. A cada erro, a imagem se revela um pouco mais.

**Jogue aqui:** https://nathdomin.github.io/adivinhe-o-pokemon/

## Tecnologias
- HTML, CSS e JavaScript puros
- [PokeAPI](https://pokeapi.co/) para os dados dos Pokémon
